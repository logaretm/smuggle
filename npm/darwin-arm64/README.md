# @smuggle-cli/darwin-arm64

This is the macOS Apple Silicon (arm64) binary for [`smuggle-cli`](https://www.npmjs.com/package/smuggle-cli).

**You should not install this package directly.** Install the main package instead:

```sh
npm install -g smuggle-cli
```

The correct platform-specific binary will be selected automatically.

## About Smuggle

Smuggle lets you test local npm packages in real consumer projects — no symlinks, no lockfile pollution, no `.npmrc` hacks.

See the [main package](https://www.npmjs.com/package/smuggle-cli) for full documentation, or visit the [GitHub repository](https://github.com/logaretm/smuggle).
